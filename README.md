# Sistema de Inventario de una Tienda

## Descripción
Proyecto desarrollado en JavaScript como parte de la Clase 3 de Desarrollo Web.

El programa simula un inventario básico de una tienda y permite administrar productos mediante arreglos, métodos y ciclos de programación.

## Objetivo
Aplicar los fundamentos de JavaScript para almacenar, consultar, modificar y recorrer información utilizando arreglos.

## Funcionalidades
- Crear un inventario de ocho productos.
- Consultar productos mediante sus índices.
- Agregar productos utilizando `push()`.
- Eliminar productos mediante `pop()` y `shift()`.
- Modificar productos mediante sus posiciones.
- Buscar productos con `includes()` e `indexOf()`.
- Recorrer el inventario utilizando `for` y `forEach()`.
- Contar productos mediante `length`.
- Realizar una cuenta regresiva con `while`.
- Calcular el valor total del inventario (actividad adicional).

## Instrucciones de ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir `index.html` en un navegador.
4. Presionar `F12` y seleccionar la pestaña Console.
5. Revisar los resultados del inventario.

No requiere Node.js, frameworks ni instalaciones adicionales.

## Conceptos aplicados
- Variables y tipos de datos.
- Arreglos e índices.
- Métodos de arreglos.
- Ciclos `for`, `while` y `forEach()`.
- Operadores aritméticos y de comparación.
- Uso de `console.log()`.

## Resultados esperados
El sistema muestra los productos registrados, los cambios realizados, la búsqueda de productos y el total de elementos disponibles.
